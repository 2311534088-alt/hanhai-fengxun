# V0.3 典型巡检任务与共振主动规避决策 Demo

## 定位与边界

本 Demo 使用 2025-11-01 至 2026-03-31 的公共再分析/模型环境数据，验证可解释的单艇避共振决策链路。它不是 SAC、强化学习、安全认证模型或真实无人艇控制系统。

来源必须按以下三层理解：

- 环境：`REAL PUBLIC ENVIRONMENT DATA - NOT IN-SITU ZHUANGHE OBSERVATION`。ERA5、WAVERYS、GLORYS 和 GEBCO 均为公共产品，不是庄河现场实测。
- 船态：`SIMULATED VESSEL STATE`。场景中的 SOG、HDG 均为任务模拟输入；没有真实 roll、pitch 或 roll rate。
- 横摇参数：`ENGINEERING_ESTIMATE / NOT_EXPERIMENTALLY_CALIBRATED`。参数是基于实艇尺度与低保真水动力模型的工程估计，不是厂家参数、实测结果或水池试验结果。

系统只输出决策建议，推进器和舵机控制保持 disabled。阈值仍为 `PRELIMINARY / NEEDS CALIBRATION`。

## 场景与数据证据

三份小型场景文件位于 `data/scenarios/`：

| 场景 | 时间（UTC） | 位置 | Hs | Tp | 波向 | 初始 SOG / HDG | 初始状态 |
|---|---|---|---:|---:|---:|---:|---|
| NORMAL | 2025-11-01 00:00 | 39.4000 N, 123.8000 E | 0.30 m | 3.17 s | 124.78° | 1.50 m/s / 304.78° | NORMAL |
| WARNING | 2025-11-03 03:00 | 40.2000 N, 122.0000 E | 0.39 m | 2.75 s | 25.94° | 1.60 m/s / 205.94° | WARNING |
| HIGH_RISK | 2025-11-01 00:00 | 39.6000 N, 123.4000 E | 0.14 m | 2.48 s | 99.93° | 2.10 m/s / 234.93° | HIGH_RISK |

Hs/Tp/波向来自 WAVERYS，风来自 ERA5，表层流来自 GLORYS，水深来自 GEBCO。每个字段都保留 source、nearest sampling、时间偏差、空间距离及 accepted/rejected；nearest-neighbour sampling 不称为最终多源融合。场景只保存采样结果、来源文件 SHA-256 和模拟船态，不复制原始 NetCDF。

## 决策搜索

`core/resonance/avoidance.py` 在 0.5–3.0 m/s 的仿真搜索边界内按 0.1 m/s 离散搜索，并检查当前航向的 ±5°、±10°、±15°。该区间不是 ZLUSV-200 厂家运营航速范围。它分别输出：

1. 只调速；
2. 只调航向；
3. 联合调速和航向。

候选必须先把 WARNING 改善为 NORMAL，或把 HIGH_RISK 改善为 WARNING/NORMAL；随后尽量减少速度变化和航向变化。当前已经 NORMAL 时保留原速度和航向。如果给定搜索边界内没有改善候选，返回 `NO_SAFE_CANDIDATE_WITHIN_SEARCH_LIMITS`，并建议 `PAUSE / RETURN ASSESSMENT`，不伪造安全解。

HIGH_RISK 场景的最终建议为仅调整模拟航向：

- 调整前：SOG 2.10 m/s、HDG 234.93°、遭遇频率 3.50548 rad/s、裕度比 0.05000、HIGH_RISK。
- 调整后：SOG 2.10 m/s、HDG 219.93°、遭遇频率 3.22081 rad/s、裕度比 0.12715、WARNING。
- 航速损失：0%；假设航段距离不变，估算航行时间变化 0%。

这只是工程判据下的风险状态改善，不证明实艇不会发生横摇或共振。

## 风险与效率口径

三种方案都调用 V0 baseline，输出 risk_score、wave/wind/motion/navigation 分量和 resonance status。由于没有 roll/pitch，motion 分量不推断姿态响应；文件中明确记录 `UNAVAILABLE - NO REAL OR SIMULATED ATTITUDE RESPONSE USED`。

baseline risk_score 与 resonance_status 是并列证据：当前 baseline 尚未把共振裕度并入总分，因此 HIGH_RISK 共振状态可能同时出现较低 baseline 分数，不能据此把 HIGH_RISK 解释为安全。

当前没有真实航速—功率曲线，因此：

- `energy_cost: null`
- `energy_model_status: REQUIRES REAL SPEED-POWER DATA`

没有使用或声称任何能耗下降百分比。

## 运行

生成证据文件（需要本机已有且校验通过、被 Git 忽略的冬季 NetCDF）：

```powershell
python tools/build_v03_mission_demo.py
```

运行不依赖原始 NetCDF 的任务级控制台 Demo：

```powershell
python -m apps.desktop.mission_demo
```

机器可读汇总为 `data/results/v0.3_mission_demo.json`。

## 仍需真实数据与校准

- ZLUSV-200 实测横摇固有周期、GM、阻尼、附加惯量与频率响应；
- 庄河实艇时间同步的 SOG、COG、HDG、roll、pitch、roll rate 和任务状态；
- 实艇航速—功率—能耗曲线；
- 共振裕度阈值的试验标定；
- 决策建议的水池、半实物和海试验证。

在这些数据和验证完成前，本 Demo 不得用于真实闭环控制。
