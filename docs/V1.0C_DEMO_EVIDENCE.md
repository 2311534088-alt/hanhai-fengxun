## 证据结构

- 环境：`REAL PUBLIC HISTORICAL ENVIRONMENT - NOT IN-SITU OBSERVATION`；WAVERYS、ERA5、
  GLORYS、GEBCO 输入 SHA-256 与 manifest 保留在机器可读文件。
- 船态与任务：`SIMULATED VESSEL STATE / SIMULATED NEAR-FARM MISSION GEOMETRY`。
- 动力学：`ENGINEERING_ESTIMATE / NOT_EXPERIMENTALLY_CALIBRATED`。
- 决策：冻结 V0.9 `DynamicMissionEngine`；没有 SAC、强化学习或 actuator interface。
- 能源：`NOT VERIFIED ENERGY FEASIBILITY`。

生成命令：

```powershell
python tools/build_v10c_competition_demo.py
```

## 窗口与选择规则

生成器选择 2026-01-24 06:00 UTC 开始的连续因果窗口，公共环境参考位置为
39.505069°N、123.344583°E。该位置是公开海事作业参考多边形的派生中心，不是官方风机坐标。

规则固定近场模拟几何、0.5 m/s 初始航速，按原生 3 h WAVERYS epoch 顺序寻找“先可接受、
后出现冻结 unsafe、冻结引擎存在可执行局部动作且重算状态改善”的最早窗口。规则禁止读取
`mission_saved`、完成结果、商业结果、策略对比；动作选择不读取未来环境。

## Before → Action → After

- Before（2026-01-24 09:00 UTC）：SOG 0.5 m/s，HDG 44.145°，Hs 0.14 m，Tp 1.88 s，
  风速 5.461 m/s；单船风险 1.19/LOW；GRID_Q90 15.045；robust 为
  `RESIDUAL_HIGH_RISK_UNDER_PARAMETER_UNCERTAINTY`。
- Action：冻结 DynamicMissionEngine 输出 `ADJUST_SPEED_HEADING`，建议 SOG 0.5 m/s、HDG
  29.145°。执行段持续 600 s、约 300 m，实际执行值与建议一致，来源为
  `SIMULATED MISSION MANEUVER`。
- After（机动结束 09:10 UTC）：以实际段终点、SOG、HDG 和因果可用环境重新调用冻结核心；
  单船风险 1.18/LOW，GRID_Q90 13.761，robust 降为 `ROBUST_MODERATE`。因此允许记录
  `RISK_IMPROVED`；这是模型重评，不是实验测量。

## 到达和巡检边界

执行轨迹真实进入距 `WT-DEMO-07` 小于 75 m 的模拟半径后才生成 `TARGET_REACHED`；记录的
到达距离约 0.4 m。随后事件为 `INSPECTION_AREA_ENTERED`、`INSPECTION_PAYLOAD_READY` 和
`INSPECTION_PAYLOAD_ACTIVE (SIMULATED)`。载荷只是状态演示，不表示检测到叶片裂纹、损伤或
任何真实缺陷。

水深约 15–20 m均是 `PUBLIC OPERATIONAL CONTEXT`。Demo 使用 near-farm deployment，不将
30–40 km 变成当前艇能力证明。GEBCO 样点为 16 m，仍是公共水深产品参考，不能用于航行安全。
