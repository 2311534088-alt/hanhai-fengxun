# V0.8 动态因果任务回放与安全约束商业验证

## 结论边界

V0.8 建立 `DYNAMIC_CAUSAL_MISSION_REPLAY`：在出航、任务点和返航阶段以 30 分钟为初步决策周期重复评价，并完整执行模拟机动、绕行、合格 HOLD 或返航。所有结果仍为 `MODEL-BASED HISTORICAL REPLAY / NOT REAL OPERATIONAL PERFORMANCE`，不是庄河现场运营率或商业价值实证。

环境来自 ERA5、WAVERYS、GLORYS 和 GEBCO 公共产品；通过现有 `MarineEnvironmentSampler` 分字段最近邻组装并保留 provenance，不能称为最终多源融合。航速、航向、路线、任务点和服务时间为模拟参数；横摇动力学为 `ENGINEERING_ESTIMATE / NOT_EXPERIMENTALLY_CALIBRATED`；风险 baseline 权重为 `PRELIMINARY / NEEDS CALIBRATION`。

## 动态决策与机动执行

每个决策 epoch 仅读取 `timestamp <= t` 的环境，记录当前位置、任务阶段、SOG、HDG、完整 MarineEnvironment、单船风险 baseline、横摇响应 proxy 和 robust status。三种内部模拟策略使用相同观测频率与动作约束。

局部候选若包含推荐 HDG，不再只应用 SOG。引擎按候选 SOG/HDG 生成 10 分钟 `MANEUVER_SEGMENT`，记录起止位置、实际执行航向和速度，再建立重新汇入任务点的路线。无法形成轨迹的建议只能是 `ADVISORY_ONLY`，不能作为已经执行的风险改善。

## HOLD 与返航

HOLD 前扫描 0、45、90、135、180、225、270、315 度可能艏向的 stationary GRID_Q90。由于没有 station-keeping 模型，艏向状态固定为 `UNKNOWN_WITHOUT_STATION_KEEPING_MODEL`。任一方向仍为 residual high 时输出 `HOLD_POSITION_UNSAFE`，禁止原地等待。合格等待最多执行一个 30 分钟 epoch；若仍未解除风险则返航。

任务出航后选择 RETURN 时，从实际当前位置模拟路线至基地，并继续计算时间、距离和风险暴露；到达基地后任务为中断/非计划返航，而不是完成。离港前共同安全筛查失败记 `PREDEPARTURE_DELAY`，不记非计划返航。

## 完成与安全指标

`TECHNICAL_SIMULATION_COMPLETED` 与 `EVIDENCE_QUALIFIED_COMPLETION` 分离。完整模拟任务超过厂家公开的 ≥4h 最低工作时间参考时，仍可技术完成，但证据状态为 `ENDURANCE_UNVERIFIED`，不进入 evidence-qualified completion 或 `MISSION_SAVED`。

安全暴露包括高风险累计时长、比例、最大连续高风险时长和按 LOW/MODERATE/HIGH 分别取 1/2/3 权重的离散 `risk_burden`。后者显著标记为 `PRELIMINARY SAFETY METRIC - NOT ACCIDENT PROBABILITY`。

`MISSION_SAVED` 同时要求同一场景 baseline 未完成、寒海完整且证据合格、续航不为未验证、危险暴露不恶化、没有未来泄漏。每个场景保留 rejection reasons。

## 360 个历史回放场景

V0.8 使用 V0.7 预先声明的 120 个冬季时间样本，交叉三个事先定义、方位不同的模拟几何：`SHORT_ROUTE`、`MEDIUM_ROUTE`、`STRESS_TEST_ROUTE`，形成 N=360。它们是 historical replay scenarios，不是 360 次独立真实巡检，也不代表庄河风机间距。

最终结果：

- `BASELINE_CONSERVATIVE`：技术完成 346/360，证据合格完成 234/360，非计划返航 7/360，离港前延迟 7。
- `LOCAL_ADJUST_ONLY`：技术完成 348/360，证据合格完成 234/360，非计划返航 5/360，离港前延迟 7。
- `HANHAI_MISSION_CONTINUITY`：技术完成 348/360，证据合格完成 234/360，非计划返航 5/360，离港前延迟 7。

Hanhai 的高风险累计暴露为 60,708.87 秒、比例 1.2392%、最长连续高风险 10,235.26 秒；保守 baseline 分别为 58,099.66 秒、1.1900%、10,794.91 秒。风险负担也略增，因此没有 evidence-qualified 完成增益，`mission_saved_count=0`。

所有策略的时间代价 P50/P90/P95/max 均为 0 秒。本次确定性样本未产生超过 1 秒的额外任务时长；指标仍完整输出，避免只报总体均值。

## 2026-02-05 压力测试动态复评

00:00 不读取 03:00。HOLD 全艏向敏感性扫描为 `HOLD_POSITION_UNSAFE`，因此不原地等待。策略先执行一次基于当前信息的低风险区域模拟绕行；下一决策点风险仍高且 HOLD 仍不安全，于是选择 RETURN，并从实际位置回放至基地。

动作链为 `REROUTE_TO_LOWER_RISK_AREA → RETURN_ASSESSMENT → CONTINUE_RETURN_TO_BASE`。任务在约 37.04 分钟后回到基地，结果为 `RETURNED_UNPLANNED / INCOMPLETE`；高风险暴露及最大连续高风险暴露均约 2,222.22 秒，证据合格完成为 false。

## 双 Gate

- `REPLAY_INTEGRITY_GATE = PASS`：因果屏障、动作/轨迹一致性、完整返航、动态风险暴露和时间统计通过开发验收。
- `BUSINESS_VALUE_STATUS = NOT_ESTABLISHED`：`mission_saved_count=0`，且没有形成安全非劣的证据合格完成增益。

这两个状态不能写成 `BUSINESS_VALUE_PROVEN`。完整机器证据由 `python tools/build_v08_dynamic_mission_replay.py` 生成到 Git 忽略的 `data/generated/`；当前冻结摘要位于 `data/results/v0.9_summary.json`。
