# 寒海风巡 V0.1 工程初始化审核说明

生成日期：2026-08-13

## 本轮范围

本轮仅完成工程初始化、统一数据模型、CSV 回放、可解释风险基线、任务状态机、模拟任务数据、最小命令行 Demo 和基础测试。

未实现 SAC、深度学习、正式 Pareto 调速、真实海洋数据接入、真实无人艇控制或最终 PySide6 界面。

## 审核重点

1. `AGENTS.md` 是否完整限定数据真实性和真实控制边界。
2. `core/models.py` 的字段、空值及异常值校验是否合理。
3. `core/risk/baseline.py` 是否保持可解释，并明确其常数不是安全阈值。
4. `core/mission/state.py` 的任务转换是否符合业务流程。
5. `adapters/replay/csv_replay.py` 是否严格按时间顺序回放。
6. `configs/zlusv200.yaml` 是否仅记录已知参数，未知参数是否为 `null`。
7. 所有样例数据是否标注 `SIMULATED / DEMO ONLY`。
8. `adapters/ros_zlusv200` 是否保持控制禁用。

## 验证命令

```powershell
python -m compileall -q apps core adapters tests
python -m unittest discover -v
python -m apps.desktop.main
```

当时打包前验证结果：10 项测试全部通过，Demo 完整输出 11 条模拟任务记录。后续阶段 A 审查已扩展测试和接口。

## 已知 TODO / 缺失真实数据

- 横摇固有周期、GM 和横摇阻尼尚未通过试验辨识。
- 缺少带来源、时间、单位及质量标记的庄河真实风浪流数据。
- 缺少 ZLUSV-200 时间同步实测航行、姿态、电池和任务事件数据。
- 最大航速、推荐工作航速及安全姿态/风浪边界尚待权威资料或试验确认。
- 风险基线的归一化常数、等级区间和建议策略尚未通过试验校准。
- ROS topic/schema、坐标系、采样率、时钟和故障模式尚待联调确认。
- PySide6 UI、报告、共振物理层、Pareto 调速均属于后续阶段。

## 数据与安全声明

`data/samples/sample_mission_001.csv` 完全为 `SIMULATED / DEMO ONLY`，不是庄河实测数据，不得用于证明无人艇性能或安全能力。V0.1 只输出决策建议，真实控制接口保持 `disabled`。原输出字段 `confidence` 后经阶段 A 审查确认只是输入完整度，当前代码已改名为 `data_quality`。
