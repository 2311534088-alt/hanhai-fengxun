# V0.1 工程初始化范围

## 已完成

- Python 3.11+ 包结构和最小启动入口。
- 统一遥测模型、CSV 顺序回放、任务状态机。
- 输出 0–10 分及解释、建议的透明规则基线；原 `confidence` 在阶段 A 审查中确认仅代表输入完整度，现已更名为 `data_quality`。
- 明确标注的完整模拟任务样例和基础单元测试。
- ZLUSV-200 已知参数配置；未知参数保持 `null`。

## 明确不在本轮

- SAC、深度学习和模型训练。
- Pareto 航速优化的正式算法实现。
- 真实/实时庄河环境数据接入。
- ROS 写控制、推进器/舵机闭环或任何自动执行建议。
- 风机缺陷检测和最终视觉 UI。
