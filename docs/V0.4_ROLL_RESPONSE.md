# V0.4 波浪激励感知的低保真横摇响应

## 模型边界

V0.4 将两个概念严格分开：

- `resonance_proximity_status` 只说明遭遇频率与工程估计固有频率的接近程度，不是最终横摇危险等级。
- `roll_response_risk` 同时使用 Hs、Tp、遭遇频率、固有频率、阻尼和相对浪向的低保真响应估计。

所有响应均标记 `LOW_FIDELITY_ENGINEERING_ESTIMATE / NOT VALIDATED AGAINST REAL ROLL DATA`，不得称为真实横摇角预测。参数仍为 `ENGINEERING_ESTIMATE / NOT_EXPERIMENTALLY_CALIBRATED`，阈值仍为 `PRELIMINARY / NEEDS CALIBRATION`。

## 公式说明

深水近似：`omega = 2*pi/Tp`、`k = omega^2/g`。显著波幅为 `Hs/2`，波坡 proxy 为 `k*Hs/2`，横浪激励因子为 `abs(sin(relative_wave_angle))`。

因此：

`roll_excitation_proxy = wave_slope_proxy * beam_excitation_factor`

标准单自由度线性系统的动态放大因子为：

`DAF = 1 / sqrt((1-r^2)^2 + (2*zeta*r)^2)`

`estimated_roll_response_rad = roll_excitation_proxy * DAF`

这里采用平方和与乘法。任务文本中出现的减号若按字面使用，会让精确共振处的开方项为负，并让“激励越强、响应反而相减”的物理意义不成立。精确共振 `r=1` 时，DAF 正确退化为 `1/(2*zeta)`。

## 集中阈值与不确定性

阈值只保存在 `configs/roll_response_baseline.json`：LOW < 8°，MODERATE 为 8–15°，HIGH >= 15°。它们只是初步工程阈值，必须由真实 roll 数据校准。

不确定性扫描覆盖自然横摇周期 1.32–2.32 s、阻尼比 0.10–0.30，共 55 个组合，输出 GRID_Q10/GRID_Q50/GRID_Q90 与最小/最大响应。它是 `DETERMINISTIC SENSITIVITY GRID`，不是统计置信区间。

## 冬季场景重筛结果

环境均来自 2025-11-01 至 2026-03-31 的 ERA5/WAVERYS/GLORYS/GEBCO 公共产品，不是庄河现场实测；SOG 与 HDG 是 `SIMULATED VESSEL STATE`。

- 原 Hs=0.14 m 场景重新分类为 `FREQUENCY_CLOSE_LOW_EXCITATION`。频率接近为 HIGH，但名义响应约 5.22°、roll risk 为 LOW，因此不再强制调速或调航向。
- MODERATE 场景：2026-03-12 12:00 UTC，39.2 N / 122.8 E，Hs 0.23 m、Tp 2.14 s，真实 WAVERYS 波向 170.48°。
- HIGH 场景：2026-02-05 00:00 UTC，39.2 N / 122.2 E，Hs 0.38 m、Tp 2.02 s，真实 WAVERYS 波向 109.66°；模拟 SOG 1.8 m/s、HDG 214.66°，相对浪向 105°。

代表性 HIGH 场景在名义参数下：

- BEFORE：遭遇频率 3.57011 rad/s，margin ratio 0.03249，DAF 2.82389，响应 29.29575°，HIGH。
- AFTER：无约束仿真搜索给出 SOG 3.0 m/s、HDG 229.66°；3.0 m/s 是仿真搜索边界，不是 ZLUSV-200 最大运营航速。遭遇频率 4.59037 rad/s，margin ratio 0.24400，DAF 1.41370，响应 13.14920°，MODERATE。
- 降幅 55.12%，必须写作 `MODEL-ESTIMATED REDUCTION / NOT EXPERIMENTALLY MEASURED`。
- BEFORE 参数网格 GRID_Q10/GRID_Q50/GRID_Q90：12.264° / 19.557° / 33.410°；AFTER：4.982° / 9.784° / 23.384°。这些分位数不表示概率或统计置信区间。

## 避险搜索与冲突记录

候选的科研敏感性范围仍限定 0.5–3.0 m/s 和当前 HDG 的 0/±5/±10/±15°。该速度区间只是 `SIMULATION_SEARCH_BOUND`。排序首先降低 roll risk，再降低 estimated roll，最后考虑速度与航向改变量。响应增加的候选不会成为推荐。如果频率 margin 变差但响应估计下降，decision_reason 会明确记录冲突；模型不会把 margin 单独当作最终风险。
