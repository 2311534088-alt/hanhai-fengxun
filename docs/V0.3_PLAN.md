# V0.3 计划：庄河真实环境数据接入 + ZLUSV-200 工程估计横摇动力学

## 目标

在 V0.2 基础上完成两件事：

1. 将 ERA5、Copernicus WAVERYS、GLORYS、GEBCO 的**真实公共数据**接入统一 `MarineEnvironment` 数据链；
2. 在缺乏实艇自由横摇试验的前提下，引入与真实参数严格区分的 **ENGINEERING_ESTIMATE** 横摇动力学配置，使共振物理模块可运行。

V0.3 仍不训练 SAC，也不向真实无人艇下发控制命令。

## 关键数据约定

项目内部统一采用：

- 方位角范围：0–360°；0°=北，90°=东；
- 环境方向统一表示**传播/运动去向（direction of travel）**；
- WAVERYS 原始波向字段为 wave **from direction**，Adapter 必须在进入核心模型前转换
