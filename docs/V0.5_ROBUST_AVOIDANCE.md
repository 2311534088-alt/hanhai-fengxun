# V0.5 参数网格感知的稳健横摇规避

## 统计口径

自然周期 1.32–2.32 s、阻尼比 0.10–0.30 的 55 个规则组合属于 `DETERMINISTIC SENSITIVITY GRID`。由于没有参数概率分布证据，结果统一写作 `GRID_Q10 / GRID_Q50 / GRID_Q90`，并明确标记 `NOT A STATISTICAL CONFIDENCE INTERVAL`。这些量不能解释为置信区间、90% 概率或统计不确定性分布。

每个动作候选都输出 minimum、nominal、GRID_Q50、GRID_Q90、maximum，以及 nominal/grid-Q90/worst-case risk。

## 稳健状态与排序

- GRID_Q90 为 LOW：`ROBUST_NORMAL`
- GRID_Q90 为 MODERATE：`ROBUST_MODERATE`
- GRID_Q90 为 HIGH：`RESIDUAL_HIGH_RISK_UNDER_PARAMETER_UNCERTAINTY`

候选依次按 GRID_Q90 risk、GRID_Q90 response、nominal response、速度变化、航向变化排序。名义响应降低但 GRID_Q90 仍为 HIGH 时记录 `NOMINAL_IMPROVES_BUT_ROBUST_RISK_REMAINS_HIGH`，不能称为安全或成功；操作建议保留 `PAUSE / RETURN ASSESSMENT`。

## 航速边界与动作约束

0.5–3.0 m/s 只标记为 `SIMULATION_SEARCH_BOUND`，不是 ZLUSV-200 运营航速范围。`configs/zlusv200.yaml` 中 `maximum_operational_speed_m_s` 保持 null，等待厂家资料或实艇速度试验。

推荐命中最小/最大速度或 ±15° 航向边界时输出：

- `speed_search_boundary_hit` / `heading_search_boundary_hit`
- `OPTIMUM_LIES_ON_SIMULATION_SEARCH_BOUNDARY`
- `decision_confidence_warning`

暂定动作限制为当前航速 ±20%，标记 `PRELIMINARY_MANEUVER_CONSTRAINT / PRELIMINARY / NEEDS REAL VESSEL VALIDATION`。因此 1.8 m/s 的连续范围为 1.44–2.16 m/s，离散搜索候选为 1.5–2.1 m/s。该约束不是厂家限制。

## 代表性场景结果

环境保持 2026-02-05 00:00 UTC、39.2 N / 122.2 E，真实公共环境 Hs 0.38 m、Tp 2.02 s、波向 109.66°；SOG 1.8 m/s、HDG 214.66° 为模拟船态。

| 方案 | SOG / HDG | nominal | GRID_Q90 | maximum | 稳健状态 |
|---|---|---:|---:|---:|---|
| BEFORE | 1.8 / 214.66° | 29.296° | 33.410° | 51.730° | RESIDUAL_HIGH_RISK |
| UNRESTRICTED_SIMULATION_BEST | 3.0 / 229.66° | 13.149° | 23.384° | 45.332° | RESIDUAL_HIGH_RISK |
| CONSTRAINED_RECOMMENDATION | 2.1 / 229.66° | 19.284° | 28.810° | 46.342° | RESIDUAL_HIGH_RISK |

无约束方案命中 3.0 m/s 和 +15° 仿真边界；受限方案命中 +15° 航向边界。两者 GRID_Q90 仍为 HIGH，因此均不得描述为稳健规避成功。

所有角度都是 `LOW_FIDELITY_ENGINEERING_ESTIMATE / NOT VALIDATED AGAINST REAL ROLL DATA`。材料中可使用 `MODEL-ESTIMATED RELATIVE REDUCTION`，不得写成实测横摇降低。
