# V1.0 产品软件

V1.0 将冻结的 V0.9 deterministic decision core 形成可运行、可解释、可演示的软件原型，不继续扩张确定性仿真核心。

## 第一交付切片

桌面端提供庄河海域任务态势、环境信息、无人艇与任务航迹、单船风险、共振接近度、低保真 roll-response proxy、决策建议、候选方案栏和任务时间线。运行：

```powershell
python -m apps.desktop.main
```

兼容命令行回放：

```powershell
python -m apps.desktop.main --console
```

第一版使用 `data/samples/sample_mission_001.csv` 提供 `SIMULATED / DEMO ONLY` 的任务阶段、航速、航向与电量时间线；环境量来自 `data/results/v0.4_roll_response_demo.json` 中可追溯的真实公共环境代表工况。两类时间戳分开显示，并明确标记 `NOT A CONTINUOUS WEATHER SERIES / NOT REAL-TIME FORECAST`。界面不生成舵机或推进器指令。

代表环境快照保留 WAVERYS、ERA5、GLORYS 与 GEBCO 的逐字段 provenance。环境采样坐标与模拟无人艇坐标严格分开；中央态势图只显示模拟任务几何，不是航海图，也不是经过验证的实际航迹。右侧调用冻结核心已有的确定性搜索，以只读方式比较只调速、只改航及联合建议；绕行在缺少航线模型时明确显示不可用。

## 产品工作流

任务选择 → 环境加载 → 无人艇/目标显示 → 航迹展示 → 风浪流风险 → 共振/横摇响应代理 → 调速/改航/绕行候选 → 理由展示 → 动态回放 → 到站/作业状态 → 返航与审计。

## 来源标签

- `REAL PUBLIC ENVIRONMENT`：公共产品环境，不是庄河现场观测；
- `PUBLIC GEOSPATIAL REFERENCE`：演示地图/参考地理背景，不是认证电子海图；
- `SIMULATED VESSEL STATE`：回放船态与任务阶段；
- `ENGINEERING ESTIMATE`：未实测标定的动力学；
- `UNAVAILABLE / REQUIRES VALIDATION`：海冰、水深或其他缺失/未验证能力。

当前地图为可审计的离线任务态势画布，不声称导航级电子海图。SEA ICE / ICE RISK 仅保留不可用占位。后续产品工作包括真实任务选择器、公共地理底图适配、完整审计导出和发布打包；任何算法变化必须另行版本化并与 V0.9 冻结结果回归比较。
