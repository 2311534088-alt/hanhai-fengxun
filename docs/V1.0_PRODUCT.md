# V1.0 产品软件（V1.0-C）

V1.0 将冻结的 V0.9 deterministic decision core 形成可运行、可解释、可演示的软件原型，不继续扩张确定性仿真核心。

## 第一交付切片

桌面端提供庄河海域任务态势、环境信息、无人艇与任务航迹、单船风险、共振接近度、低保真 roll-response proxy、决策建议、候选方案栏和任务时间线。运行：

```powershell
python -m apps.desktop.main
```

兼容命令行回放：

```powershell
python -m apps.desktop.main --console
```

V1.0-B 使用 `data/replay/v1.0b_synchronized_historical_mission.json`。同一 replay clock 的每一条记录同时包含经 `MarineEnvironmentSampler(timestamp, latitude, longitude)` 获取的真实公共历史环境和模拟船态，明确标记 `NOT REAL-TIME FORECAST / NOT IN-SITU OBSERVATION`。界面不生成舵机或推进器指令。

连续窗口为 2026-02-21 18:00 UTC 至 2026-02-23 00:00 UTC。选择规则只使用固定参考点窗口内 Hs 与风速的归一化变化幅度，禁止读取策略建议、`mission_saved`、任务完成或商业结果。生成命令：

```powershell
python tools/build_v10b_synchronized_replay.py
```

记录保留 WAVERYS、ERA5、GLORYS 与 GEBCO 的逐字段 provenance、时间偏差、空间距离与接受状态。产品决策统一经过 `apps/desktop/frozen_core_facade.py`：风险、共振、稳健参数扫描、受约束建议、无限制仿真敏感性最优和任务级 advisory 均来自冻结 core；GUI 不再根据风险等级自行映射任务动作。

## 产品工作流

任务选择 → 环境加载 → 无人艇/目标显示 → 航迹展示 → 风浪流风险 → 共振/横摇响应代理 → 调速/改航/绕行候选 → 理由展示 → 动态回放 → 到站/作业状态 → 返航与审计。

## 来源标签

- `REAL PUBLIC ENVIRONMENT`：公共产品环境，不是庄河现场观测；
- `PUBLIC GEOSPATIAL REFERENCE: NOT YET LOADED IN MAP`：公共地理底图尚未接入；
- `SIMULATED MISSION GEOMETRY: ACTIVE`：任务轨迹为模拟几何；
- `SIMULATED TURBINE LAYOUT`：风机点位和目标风机均为模拟布局；
- `SIMULATED VESSEL STATE`：回放船态与任务阶段；
- `ENGINEERING ESTIMATE`：未实测标定的动力学；
- `UNAVAILABLE / REQUIRES VALIDATION`：海冰、水深或其他缺失/未验证能力。

公共上下文只使用已声明的庄河项目裁剪框（121.5–124.5°E、38.5–40.5°N，非行政边界）；公共地理底图尚未加载。中央画布中的风场参考范围、逐台风机、目标风机、部署点和任务航迹均为模拟布局，不声称导航级电子海图。`SEA ICE / ICE RISK` 保持 `UNAVAILABLE / FUTURE EXTENSION`。0.5–3.0 m/s 只表示 `SIMULATION_SEARCH_BOUND`，±20% 只表示 `PRELIMINARY / NEEDS REAL VESSEL VALIDATION`。

## V1.0-C Competition Demo

V1.0-C 的任务级执行真值来自冻结的
`core.mission.dynamic_replay.DynamicMissionEngine`。它保留完整 unsafe 定义：稳健残余 HIGH
或单船风险 HIGH 任一成立即为 unsafe，并包含 30 min candidate rollout、HOLD 艏向敏感性、
当前快照路线筛选、目的地感知与返航判断。`apps/desktop` 不复制 CONTINUE、ADJUST、REROUTE、
HOLD 或 RETURN 策略。

```powershell
python tools/build_v10c_competition_demo.py
python -m apps.desktop.main
python -m apps.desktop.main --console
```

生成器以真实公共冬季环境、固定模拟近场几何和冻结引擎确定性生成
`data/replay/v1.0c_competition_demo.json`。当引擎建议局部调整时，生成器保存并播放真正的
`SIMULATED MANEUVER SEGMENT`：推荐与执行 SOG/HDG 一致，位置和航迹随执行段更新，段末状态
重新调用冻结核心评估。只有重算后的 robust 状态、GRID_Q90 或单船风险真实改善，才产生
`RISK_IMPROVED`。事件包含环境数据时刻、任务时刻和决策 epoch；播放可压缩视觉时间，但不改
历史 timestamp。

庄河Ⅲ公开业务背景登记在 `data/context/zhuanghe_public_operational_context.json`：72 台风机、
约 47.7 km²、南北约 8.6 km、东西约 7.7 km、中心离岸约 22.2 km，以及运维公开资料中的
庄河港至风场单程约 30–40 km、水深约 15–20 m。它们只属于
`PUBLIC OPERATIONAL CONTEXT`，不进入风险阈值、横摇模型或任务策略。当前缺少官方逐台风机
坐标，因此 72 台图标、`WT-DEMO-07`、部署点与任务轨迹全部是
`SIMULATED TURBINE LAYOUT / SIMULATED NEAR-FARM DEPLOYMENT`。30–40 km 只说明既有运维背景，
不是 ZLUSV-200 续航或运营能力证明。

采用 near-farm mission 是因为当前没有真实 speed-power 曲线、任务载荷能耗、续航试验与
真实部署方案。抵达目标只说明执行轨迹进入 75 m 的 `SIMULATED MISSION PARAMETER` 半径，随后
载荷可显示 READY/ACTIVE（SIMULATED）；软件不声称发现裂纹、识别损伤或完成真实风机巡检。
GEBCO 数值单独标记 `PUBLIC BATHYMETRY REFERENCE - NOT FOR NAVIGATIONAL SAFETY`，与公开业务
水深不一致时显示 `PUBLIC PRODUCT / SAMPLING DIFFERENCE`。

事件链与15秒视频数据接口分别保存在 `event_markers` 和
`data/replay/v1.0c_video_storyboard.json`；本轮只生成结构化数据，不生成视频。完整证据见
`docs/V1.0C_DEMO_EVIDENCE.md`。所有结果仍是模型历史回放，不是实艇运营性能；
`BUSINESS_VALUE_STATUS=NOT_ESTABLISHED`，不得显示 MISSION SAVED 或任务完成率提升。
