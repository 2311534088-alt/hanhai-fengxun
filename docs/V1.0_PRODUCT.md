# V1.0 产品软件（V1.0-B）

V1.0 将冻结的 V0.9 deterministic decision core 形成可运行、可解释、可演示的软件原型，不继续扩张确定性仿真核心。

## 第一交付切片

桌面端提供庄河海域任务态势、环境信息、无人艇与任务航迹、单船风险、共振接近度、低保真 roll-response proxy、决策建议、候选方案栏和任务时间线。运行：

```powershell
python -m apps.desktop.main
```

兼容命令行回放：

```powershell
python -m apps.desktop.main --console
```

V1.0-B 使用 `data/replay/v1.0b_synchronized_historical_mission.json`。同一 replay clock 的每一条记录同时包含经 `MarineEnvironmentSampler(timestamp, latitude, longitude)` 获取的真实公共历史环境和模拟船态，明确标记 `NOT REAL-TIME FORECAST / NOT IN-SITU OBSERVATION`。界面不生成舵机或推进器指令。

连续窗口为 2026-02-21 18:00 UTC 至 2026-02-23 00:00 UTC。选择规则只使用固定参考点窗口内 Hs 与风速的归一化变化幅度，禁止读取策略建议、`mission_saved`、任务完成或商业结果。生成命令：

```powershell
python tools/build_v10b_synchronized_replay.py
```

记录保留 WAVERYS、ERA5、GLORYS 与 GEBCO 的逐字段 provenance、时间偏差、空间距离与接受状态。产品决策统一经过 `apps/desktop/frozen_core_facade.py`：风险、共振、稳健参数扫描、受约束建议、无限制仿真敏感性最优和任务级 advisory 均来自冻结 core；GUI 不再根据风险等级自行映射任务动作。

## 产品工作流

任务选择 → 环境加载 → 无人艇/目标显示 → 航迹展示 → 风浪流风险 → 共振/横摇响应代理 → 调速/改航/绕行候选 → 理由展示 → 动态回放 → 到站/作业状态 → 返航与审计。

## 来源标签

- `REAL PUBLIC ENVIRONMENT`：公共产品环境，不是庄河现场观测；
- `PUBLIC GEOSPATIAL REFERENCE: NOT YET LOADED IN MAP`：公共地理底图尚未接入；
- `SIMULATED MISSION GEOMETRY: ACTIVE`：任务轨迹为模拟几何；
- `SIMULATED TURBINE LAYOUT`：风机点位和目标风机均为模拟布局；
- `SIMULATED VESSEL STATE`：回放船态与任务阶段；
- `ENGINEERING ESTIMATE`：未实测标定的动力学；
- `UNAVAILABLE / REQUIRES VALIDATION`：海冰、水深或其他缺失/未验证能力。

公共上下文只使用已声明的庄河项目裁剪框（121.5–124.5°E、38.5–40.5°N，非行政边界）；公共地理底图尚未加载。中央画布中的风场参考范围、逐台风机、目标风机、部署点和任务航迹均为模拟布局，不声称导航级电子海图。`SEA ICE / ICE RISK` 保持 `UNAVAILABLE / FUTURE EXTENSION`。0.5–3.0 m/s 只表示 `SIMULATION_SEARCH_BOUND`，±20% 只表示 `PRELIMINARY / NEEDS REAL VESSEL VALIDATION`。
