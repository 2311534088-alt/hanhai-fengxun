# V0.7 因果完整任务回放

## 定位与证据边界

V0.7 修正 V0.6 中“动作等同任务结果”、未来历史数据泄漏、航段起点一次采样和风险暴露硬编码等问题。结果均为 `MODEL-BASED HISTORICAL REPLAY / NOT REAL OPERATIONAL PERFORMANCE`，不是庄河风场运营率、现场实测结论或商业价值实证。

环境使用 Copernicus Marine WAVERYS 公共再分析/模型产品；航速、航向、路线、任务点和巡检服务时间均为模拟任务参数；横摇响应参数为 `ENGINEERING_ESTIMATE / NOT_EXPERIMENTALLY_CALIBRATED`。系统不含 SAC、强化学习、真实推进器/舵机指令或最终 GUI。

## 动作与结果分离

`CONTINUE`、`ADJUST_SPEED_HEADING` 和 `REROUTE` 仅对应 `IN_PROGRESS`；`HOLD_AND_REASSESS` 仅对应 `PENDING_REASSESSMENT`；它们都不能直接产生 `mission_completed=true`。只有时间线依次包含 `PRE_DEPARTURE → OUTBOUND → ON_STATION → SIMULATED_INSPECTION_SERVICE_COMPLETED → RETURNING → MissionState.COMPLETED` 时，任务才计为完成。

## 因果历史回放

`CAUSAL_HISTORICAL_REPLAY` 在决策时刻 `t` 仅允许动作选择读取 `timestamp <= t` 的环境。未来历史环境只可用于已执行路径的 `OUTCOME_EVALUATION`。若局部调整和当前快照下绕行筛选都不接受，策略 HOLD 3 小时；到 `t+3h` 才读取当时环境重做决策，并不提前知道环境会改善。

`ORACLE_HISTORICAL_LOOKAHEAD` 保留为 `ORACLE UPPER BOUND / NOT OPERATIONALLY AVAILABLE`，不参与 V0.7 商业指标。V0.6 四案例降级为 development smoke test。

## 时间、续航与风险暴露

任务记录出航、HOLD、绕行额外、模拟巡检服务、返航和总历时。HOLD 时间不是零成本；缺少真实驻留功率，因此 `hold_energy=null / REQUIRES REAL POWER DATA`。

厂家资料仅支持 `manufacturer_guaranteed_work_time_reference_h=4`，含义是 `MINIMUM PUBLISHED WORK-TIME REFERENCE - NOT MAXIMUM ENDURANCE`。超过 4 小时记录 `EXCEEDS_PUBLISHED_MINIMUM_REFERENCE` 和 `ENDURANCE_FEASIBILITY_UNVERIFIED`。约 28.15 km 单程路线标记为 `STRESS-TEST SIMULATED ROUTE`，不代表庄河实际巡检距离。

路线按固定时间间隔推进，逐点计算到达时间和位置，并读取该时空位置历史 WAVERYS 环境。`high_risk_exposure_steps/time`、`moderate_risk_exposure_time`、`total_evaluated_time` 和 `risk_exposure_ratio` 均由逐点采样时长累计，不再用 RETURN 0/1 硬编码。

## 确定性 120-case 对比

在固定模拟出发点对 2025-11 至 2026-03 每月全部 3 小时 WAVERYS 时间点按 `Hs/Tp²` 排序，划分 lower/middle/upper 三个激励层，每层等距选择 8 个，共 `5 × 3 × 8 = 120` case。抽样不查看策略结果；规则和 case ID 均保存在机器可读结果中。

三种策略均标记为 `INTERNAL SIMULATION BASELINE`：

1. `BASELINE_CONSERVATIVE`：持续 residual high risk 时 RETURN。
2. `LOCAL_ADJUST_ONLY`：只允许局部调速/调向，失败后 RETURN。
3. `HANHAI_MISSION_CONTINUITY`：adjust → reroute → causal hold/reassess → return last。

结果：baseline 116/120 完成、4/120 非计划返航；local-only 118/120 完成、2/120 非计划返航；Hanhai 120/120 完成、0/120 非计划返航。严格 `mission_saved_count=0`：依赖 3 小时 HOLD 的两个任务超过当前 4 小时最低公开工作时间证据，且不满足“不增加不可接受风险”的业务证据条件。因此不能声称商业价值已成立。

## Business Value Gate

自动 gate 检查 HOLD 未直接算完成、无未来动作泄漏、暴露来自时空采样、MISSION_SAVED 要求完整完成、总时间已计算。当前为 `BUSINESS_VALUE_EVIDENCE=DEVELOPMENT_PASS`，只说明上述工程缺陷已消除，不等于实证商业价值。
